# Spike S-03 — Replay feasibility (RW-03, XHigh)

Date: 2 Nov 2026 · Resolves: TRD Q3 · TASKS S-03 · effort_plan RW-03
Probe: throwaway zero-dependency Node app in `/tmp/rw-s03` (not repo code;
no LLM/agent generation — AGENTS A5b). Cost: 0 API calls.

## What was tried (exact commands)

```sh
# /tmp/rw-s03/repo: git repo, base commit (GET /health, GET /items total=1000)
# branch pr-head: total -100 (total=900). Branch named `head` collides with
# HEAD ref — use `pr-head` (finding #1).
git worktree add --detach ../wt-base main   # plain `add ../wt-base main`
                                            # fails: main already checked out
git worktree add ../wt-head pr-head
node /tmp/rw-s03/run.mjs   # spawns both servers (detached, env allow-list:
                           # PORT, NODE_ENV=test, FROZEN_TIME, SEED=42,
                           # EXTERNAL_MODE=mock), waits /health, runs scenario
git worktree remove ../wt-base; git worktree remove ../wt-head; git worktree prune
docker info   # daemon not running
```

## Observed behaviour

1. **Two-worktree replay works.** Health wait: base 81 ms, head 68 ms.
   One scenario (`GET /items`): base run twice → byte-identical bodies
   (determinism / base double-run premise of TRD §7.4 holds for a
   deterministic app); head differs exactly as designed
   (`total 1000 → 900`, `observedChanged: true`). Scenario wall-clock
   after spawn: 87 ms. Teardown (process-group SIGTERM) frees 8101/8102 —
   verified with curl after exit.
2. **Sandbox finding (environment, not design).** Inside the default shell
   sandbox, `listen 127.0.0.1:8101` fails `EPERM` and the child exits 1.
   The identical run with network permission succeeds. Consequence for
   C-03: the replay runner must either run outside that sandbox profile
   or fail loudly with this exact error surfaced — never as STATIC-ONLY
   without a reason (PRD US-5).
3. **Worktree rules confirmed.** A branch already checked out in the main
   repo cannot be added as a second worktree; base must be added
   `--detach` (or from a bare/secondary checkout). `git worktree remove` +
   `prune` clean up fully; no `.git/worktrees` residue. TRD §7.2 step 1
   must say `--detach` for base.
4. **Dependency strategy (decision).** Probe has zero deps, so install
   cost is unmeasured. Adopt TRD §7.2 step 2 as written, with the local
   toolchain fact from S-01/S-02: pnpm is available as `corepack pnpm`
   (9.15.4); `corepack enable` fails in this sandbox (symlink outside
   workspace). Rule: symlink `node_modules` when `package.json`/lockfile
   are unchanged base↔head; else `corepack pnpm install --frozen-lockfile`
   in the worktree. Measure the install path in C-02 (IT-REP-10).
5. **Network isolation on this machine (macOS/Darwin).** `unshare` absent;
   Docker CLI present but daemon not running → neither TRD §9 mechanism
   is available here today. Fallback stands: `EXTERNAL_MODE=mock` +
   env allow-list + documented residual risk, with a UI warning when
   isolation is unavailable (AUDIT §3.2). SEC-01 stays open until Docker
   or an equivalent is actually exercised.

## Decision

Replay strategy is **viable as designed** (TRD §7.2–§7.4), with three
amendments carried into C-02/C-03: (a) base worktree `--detach`;
(b) branch names must not collide with `HEAD`; (c) listen-`EPERM` is a
distinct, loudly-reported failure mode. Subject-app execution stays
confined to `packages/replay` helpers (AGENTS A5.2); this spike ran only
in `/tmp`.
